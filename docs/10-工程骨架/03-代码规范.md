# 10-03 · 代码规范（强制，与任何 prompt 冲突时以本文为准）

> 适配自用户既有的规范基线（mcp-drift/docs/07-code-standards.md，2026-09 拷问沉淀），按本项目技术栈调整。**所有会话提交前按 §10 自查清单过一遍。**

## 1. 注释

**语言与格式**：
- 注释一律**中文**；标识符（函数/变量/类型名）一律**英文**
- 注释**不用标点符号**（不用逗号 句号 顿号 冒号），用**空格分句**，每句一个完整意思
- 注释要**详细** 宁多勿少

**密度要求**：
- 每个**导出函数/类/模块**必须 JSDoc：用途 参数 返回 抛出什么异常
- **函数体内逐段有注释**：每个逻辑块上方一行段落级说明
- **决策注释**：写「为什么这么做 为什么不用别的方案」（本项目的高价值点：为什么不用 redlock、为什么 RRF 在应用层、为什么 epoch 要存 DB——这些注释就是面试答案）
- 禁止废话注释（「这行在干嘛」类）

**本项目的核心资产强制注释**（对应参考规范的「安全正则」条款）：
- **Lua 脚本**（锁三段）：中文说明 + 为什么必须 Lua（原子性）+ 一个竞态场景描述
- **raw SQL**（向量检索/epoch 自增）：中文说明 + 为什么不能走 ORM + 参数如何防注入
- **system prompt 模板**（六个数字员工）：中文说明设计意图 + 禁改提示
- 没有注释的 Lua/SQL/prompt **不许合入**

## 2. 可读性与命名

- 变量名 1-3 个英文词（`sessionRec` 不用 `latestConversationSessionRecord`）；允许 `ctx config rec def res opts props`；循环 `i j`
- 禁拼音 禁歧义缩写 禁 `dataInfoHelper` 式堆砌
- 函数内逻辑块之间**空行分隔**，不许一坨
- 函数名动词开头（`acquireLock` `hybridSearch` `buildToolbox`）；布尔值 `is/has/can` 前缀

## 3. 封装（反过度抽象）

- **三次法则**：第 2 次重复允许复制，第 3 次才提取；抽象必须有真实三处重复做证据
- **禁止**：单实现 interface（契约桩除外——10-骨架/04 定义的跨模块契约必须 interface）；工厂函数；「以后可能」的泛型/配置项/回调；无调用者的预留参数
- **单向依赖**：`gateway → 无依赖`，`rag → gateway`，`runtime → gateway+rag+skills+tenant`，`tenant → 无`（被别人依赖），`web → shared`。**禁止反向**（rag 不得 import runtime）

## 4. 长度红线（软性）

- 函数 ≤50 行 文件 ≤300 行；超限要么拆分 要么文件头注释写明为何不能拆（长 system prompt、Lua 脚本、种子数据是合法例外）

## 5. TypeScript

- tsconfig `strict: true` + `noUncheckedIndexedAccess: true`（三端统一：api/web/shared）
- ESLint `no-explicit-any` = **error**；不确定类型用 `unknown`+收窄
- `as` 断言旁必须有注释说明为什么安全
- **错误处理**：自定义错误类继承 Error 带 `code`（如 `LockAcquireError` `RouteExhaustedError` `TenantIsolationError`）；正常 try/catch+throw；不搞 Result/Either；错误消息**英文**可搜索
- Nest controller 一律 zod 校验入参（Standard Schema 直挂或 pipe）

## 6. 依赖（白名单制）

- 能用已有依赖解决就**不新增**；新增须走「任务报告写理由 → 用户确认」流程（并行会话同时 pnpm add 会损坏 lockfile，见 10-骨架/01 §4）
- 禁大工具库（lodash 类）与功能重叠包
- 当前白名单（地基冻结，任务 0 装齐）：api：`@nestjs/*` `@nestjs/bullmq` `bullmq` `ioredis` `ai` `@ai-sdk/openai-compatible` `@ai-sdk/deepseek` `@prisma/client` `@prisma/adapter-pg` `pg` `zod` `pdf-parse` `mammoth` `@node-rs/jieba`；web：`next` `react` `react-dom` `ai` `@ai-sdk/react` `zod`；shared：`zod`；mock-rpa：`hono` `@hono/node-server` `zod`；dev：`typescript` `tsx` `@nestjs/cli` `prisma` `vitest` `@nestjs/testing` `eslint`（web 系）`@types/*`
- 例外追加同样走确认流程（如 P2 若需 html 表格解析小包）

## 7. 语言分工（对参考规范的一处适配，理由备案）

- **用户可见 UI 文案：中文**——产品定位是国内电商场景 demo，受众含中国面试官（参考规范面向国际化 MCP 工具所以英文，本项目有意偏离，已在文档备案）
- **代码错误消息/日志 code：英文**（可搜索）
- **README：中英双语**（README.md 英文为主 + README.zh-CN.md 中文全量，K 任务产出）
- **注释/测试名：中文**（§1 §8）

## 8. 测试

- describe/it 用**中文**：`it("双路召回在 embedding 不可用时降级为纯词法", ...)`
- 测试名即文档：一眼看懂测什么
- 复杂 setup 必须中文注释说明场景
- 并行任务的单测**不得依赖其他模块的数据库数据**（自建自清理 fixture；用唯一 email/键名防串扰）

## 9. Git commit

- **中文 20 字以内**，格式 `<任务>: 概要`：`任务0: 基座就绪`、`A-网关: 降级链完成`、`B-RAG: 双路召回`
- 粒度：一功能一 commit；不攒大坨不逐行
- 并行会话**不主动 commit/push**——完成即停，由用户（或串行集成任务 J）审后统一提交（多会话并发 commit 会交错污染历史）

## 10. 硬红线与自查清单

硬红线（违反即返工）：
- [ ] 禁死代码（注释掉的代码要删 git 有历史）
- [ ] TODO 必须带日期或 issue 号：`// TODO(2026-10-08) 原因`——无主 TODO 视为违规
- [ ] 禁循环依赖（§3 的单向图）
- [ ] 禁碰共享文件（10-骨架/01 §1 的 ★ 标记文件）与别人的目录

提交前自查：
- [ ] 导出项有 JSDoc 函数体内分段注释 注释无标点空格分句
- [ ] 变量名 ≤3 词 块间空行
- [ ] 无单实现 interface（契约桩除外）无工厂无预留参数
- [ ] 无 any 无未注释 as
- [ ] Lua/SQL/prompt 有强制注释
- [ ] 错误消息英文 UI 中文 commit 中文 ≤20 字
- [ ] `pnpm typecheck && pnpm test` 全绿（只跑自己任务的测试范围）

## 11. 好坏对照（一段示例）

**好**（本项目目标风格）：

```typescript
/**
 * 获取会话锁 不阻塞 立刻返回成败
 * 为什么不用 redlock: 单 Redis 效率型锁足够 且 redlock 休眠多年
 * 正确性由 DB epoch 兜底 见 session-lock.service.ts 头注释
 * @param sessionId 会话 id
 * @returns 持有凭证 token 失败返回 null（被别人持有）
 */
export async function tryAcquire(sessionId: number): Promise<string | null> {

  // 每次获取生成新 token 释放时校验 防误删别人的锁
  const token = randomUUID()

  // SET NX PX 原子的「不存在才设置 带过期」
  const ok = await redis.set(`lock:session:${sessionId}`, token, 'PX', LOCK_TTL_MS, 'NX')

  return ok === 'OK' ? token : null
}
```

```typescript
// 获取锁
export async function getLock(id: any): Promise<any> { /* TODO 修一下 */
  const theLockKeyStringForThisConversationSession = ...; const r = await redis.set(...); return r }
```

## 12. 附注（建议非强制）

- `src/**` 服务层少用 console（输出走返回值 异常走 throw）；console 集中在 worker/脚本/CLI 入口
- 环境变量一律经 `EnvService` 读取 禁止业务代码直接 `process.env`
