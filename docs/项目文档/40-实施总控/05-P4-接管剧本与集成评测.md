## 1. 前置

- P3 全勾。

## 2. 任务清单

1. **demo:scenario 一键剧本**（scripts/）：注册企业 → 邀请 → 订阅 → 授权 → 上传知识库 → 接管三连会话（售后侠 → 扫雷 → 周报姬）→ ops 报表，全程断言 + 录屏友好输出；全新 db 重置后可重放；
2. **管理流真实操作走查**：模板 DRAFT→PENDING_REVIEW→PUBLISHED（含驳回分支）→ 订阅锁定 v1 → 发布 v2 → 验证不主动升级仍是 v1 → 显式升级 → AuditLog 全记录（00-总览/03 §3 订阅锁定语义）；
3. **评测终版**：eval 终表（三组消融 + 拒答双向 + 成本/延迟 P50/P95），badcase 抽 10 条归因写入 30-评测方案/结果分析；
4. **降级演练四连**并留记录：停 embedding（词法降级）/ 错 provider key（路由降级）/ 停 Redis（明确报错不静默）/ 同会话锁竞争（排队）；
5. **ops 成本报表对账**：报表汇总数字 = usage_records 直查结果（Decimal 精度核对）；
6. **集成问题清零**：并行期对桩的假设逐一兑现；契约不合理走变更提案流程（10-骨架/04 §9），一次只一个会话改契约文件。
