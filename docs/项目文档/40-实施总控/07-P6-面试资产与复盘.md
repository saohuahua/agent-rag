# 40-07 · P6 面试资产与复盘

> 目标一句话：把项目变成简历与面试战斗力——数字盘点、材料生成、演练闭环。技术再好，讲不出来就没有简历价值（归档方案 §六教训 4）。

## 1. 前置

- P5 全勾。

## 2. 任务清单

1. **数字盘点表**：评测终表 / 成本（元每查询、月预算场景推演）/ 延迟 P50-P95 / 隔离测试数量 / 消融差值——全部来自真实运行，红线见 00-总览/01 §2 与 00-总览/04；
2. **简历终稿**：对照 00-总览/04 保真度追溯表逐行自检，20 行全绿才准写上简历；
3. **材料生成**：用 /project-guide 生成导学与面经；用 /interview 提取 Claim 做模拟追问；
4. **演练闭环**：20 个追问模拟（合上文档能答才算过），答不上的回炉对应文档章节；
5. **叙事主线定稿**：三句话电梯版 + 深挖题答案索引（每个答案指向具体文档章节，如「为什么不用 redlock → 00-总览/02 §4」）；
6. **复盘会**：决策史走读（99-归档 §六：为什么放弃财报 RAG、方法论如何迁移）+ 本项目踩坑 top5 沉淀。

## 3. 验收门槛

- [ ] 20 个追问模拟通过；
- [ ] 简历终稿定稿，demo 链接可访问，录屏三段齐备。
