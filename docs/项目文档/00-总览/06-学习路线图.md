# 00-06 · 学习路线图

> 写给用户本人（Vue 前端背景、React 新手、RAG/Agent 新手）：概念依赖地图 + 每个任务包学什么 + 怎么验证学会了。代码由 AI 会话写，你的学习材料是「文档 + 代码走读 + 每阶段与主会话的讲解对话」。

## 1. 概念依赖地图（先整体后局部）

```
[基础层]  HTTP/JSON → REST API → SSE 流式 → Docker（容器=进程的打包）
              │
[数据层]  关系库/SQL → Prisma ORM → 迁移 → 物化路径(树) → 多租户(行级过滤)
              │
[AI 层]   token/上下文窗口 → embedding(字→坐标) → 余弦距离 → HNSW 近似最近邻
              │            → BM25/词法检索 → RRF 融合 → 降级设计
              │
[Agent层] function calling(LLM调工具) → agent loop → 流式协议 → 会话状态
              │            → 分布式锁(SET NX) → fencing token → 按序接管
              │
[平台层]  网关(路由/计量) → 订阅/版本锁定 → 授权 → 蓝绿部署 → CI
```

**学习原则**：每个概念先问「业务上为什么需要它」（答案都在 00-01 业务背景第 4 节），再看原理，最后看代码走读。

## 2. 你的背景映射表（Vue/前端 → 本项目）

| 你已会的 | 直接迁移到 |
|---|---|
| Vue 组件/响应式 | React 组件（心智差异：ref/watch → useState/useEffect，见 04 表） |
| axios 拦截器/路由守卫 | Nest 的 Guard/Interceptor（同是中间件思想） |
| Pinia 状态管理 | React Context + hooks（以及服务端 ALS——「服务器版的 Context」） |
| Vite 工程化 | pnpm workspace monorepo |
| EventSource/SSE 消费 | 同一概念，但本项目的流协议是 AI SDK 的 UI Message Stream |

**React 需要专门补的**：JSX、useEffect 依赖数组心智、受控组件、App Router 的 server/client 组件边界。建议在 E（前端）任务跑的时候，边读代码边对照写一个「Vue→React 速查」笔记。

## 3. 按任务包的学习计划

| 任务包 | 你要学懂的概念（验收=能复述） | 代码走读入口 |
|---|---|---|
| 0 基座 | monorepo 为什么、docker compose 起了什么、一次 LLM 调用里发生了什么（messages→token→流式分片→usage）、密钥为什么只在 env | apps/api/src/main.ts → gateway 控制器 |
| A 网关 | 路由与降级（类比 axios 重试拦截器）、token 怎么变钱（价格×用量）、Decimal 为什么不用 number | gateway.service.ts |
| B RAG | embedding=语义坐标、中文为什么要分词、RRF 数学（只用排名）、降级=可用性设计 | retrieval.service.ts + ingest worker |
| C Runtime | **全项目最重**：agent loop、工具调用协议、分布式锁（SET NX+Lua+watchdog）、fencing token（Kleppmann：锁也不绝对安全→DB 纪元兜底）、按序接管 | session-lock.service.ts + turn worker |
| D 多租户 | 隔离三方案（库/schema/行）的取舍、ALS=服务器版 Context、不可变版本=npm 语义、物化路径 | context/ + prisma 扩展 |
| E 前端 | useChat + transport、SSE 消费、React hooks 心智（对照 Vue） | apps/web/app/(app)/chat |
| F 语料 | 数据质量决定 RAG 上限；采集与清洗记录同样是有讲头的工程 | corpus/README |
| J 集成 | 端到端走一遍完整剧本；看评测数字怎么产生 | eval 脚本 + demo 剧本 |
| K 交付 | 反向代理/ACME、蓝绿=两份容器一个开关、expand-contract、CI 流水线 | deploy 脚本 + 上线手册 |

## 4. 学习方法（固定动作）

1. **费曼式**：每个任务包完成后，让主会话对你做一次讲解（你提要求），然后你反过来讲给它听——它纠正。
2. **每篇文档末尾的自测题**是硬验收：合上文档答不上=没学会，回炉。
3. **面试模拟**：全部完成后用 `/interview` 和 `/project-guide` 技能生成面经并演练；20 个追问的答案都长在 docs 里。
