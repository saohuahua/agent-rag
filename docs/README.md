## 阅读顺序

- **想理解项目**（用户本人）：00-总览/01 业务背景 → 02 架构 → 06 学习路线图 → 按阶段读 08-阶段总结
- **想实现代码**（AI 会话）：README → 10-工程骨架/03 代码规范 → 00-总览/03 领域模型 → 对应模块规格 → 40-总控自己的阶段 → 对应 prompt

## 文档纪律

1. **数字必须真实**：文档中所有性能/成本/评测数字必须来自真实运行，禁止编造；标注「待实测」的占位除外。
2. **文档先于代码**：改行为先改文档（本文件夹），实现跟随文档；发现文档错误当场修正并注明日期。
3. **教学式**：模块规格每篇含「原理与为什么」小节——代码会话写代码注释时直接复用其中的表述。
4. 每篇文档末尾有**自测题**（面向用户学习，能复述才算读明白）。
