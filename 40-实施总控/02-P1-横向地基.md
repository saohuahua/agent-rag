## 4. 各任务关键点

- **A**：降级链按 alias+priority 顺序尝试，全失败抛 RouteExhaustedError；LLM/embedding 记账在 GatewayService 内部 onFinish 完成（含失败记录 success=false）；
- **A 冒烟（本阶段硬验收）**：curl `/v1/chat/completions` 一次，usage_records 落一行，手工按官方价目计算与 costCny 分位级一致——这是归档方案 P0「冒烟一次精确费用可报出」的迁移落点；
- **A 首日隐藏验证**：AI SDK 7 ESM-only × Nest CJS 的 require(esm)（Node ≥22.12），失败走风险手册 §1.4；
- **D**：Prisma 租户扩展挂载是唯一共享文件触碰例外 → 产出补丁说明，**用户手动应用**（10-骨架/04 §6）；隔离测试矩阵立框架，约定「每条 raw SQL 一个隔离测试」，本期先覆盖扩展自身与部门子树查询；
- **G**：接口全部 zod 校验，种子工单 ≥20 条，README 记接口清单；
- **F**：只收公开可访问的平台规则页，corpus/README 记录来源与清洗步骤（合规红线）；golden 题双校验（LLM 预标注 + 人工抽检 10%，沿归档方案 §三）。
