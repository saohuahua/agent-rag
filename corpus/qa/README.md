# corpus/qa/ · 客服常见问答对（FAQ）

> 任务 F 的「行业 FAQ」交付物。把 `rules/` `helpdocs/` 的规则原文**重组为问答对**，用途：① 客服场景演示（`rule-qa` 小规的少样本/示例）；② 生成层评测时的答案风格参照；③ 面试时展示「规则 → 可答问题」的整理能力。

## 1. 与检索语料的关系

- **本目录不进入检索入库**：`corpus-ingest.ts` 只读 `laws/ rules/ helpdocs/` 三个目录，`qa/` 是派生内容，不重复入库（避免同一事实被 double-count）。
- 每个问答对标注 `source_docs`（指向真实存在的 doc_id），**答案严格来自原文，无任何编造**。
- 若将来希望 QA 对也参与检索，需在 `corpus-ingest.ts` 的 `CORPUS_SUBDIRS` 加入 `qa`（当前未加，属有意为之）。

## 3. 合规说明

- 全部问答对派生自已收录的语料，事实与数字均来自原文，无虚构。
- 问答对是对规则的重组表述，不改变原文含义；涉及具体条款时保留条文号便于回溯。
