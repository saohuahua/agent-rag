# 售后政策常见问答（FAQ）

## 七天无理由退货

**Q1：抖音"7天无理由退货"的时限从哪天起算？**

A：消费者在商品物流显示签收后的七天内（次日 0 点起算），对支持七天无理由退货并符合完好标准的商品，可发起七天无理由退货申请。

*依据：RULE-001 抖音电商"7天无理由退货"规则*

**Q2：商家能否给同一商品同时配置多个"7天无理由退货"规则？**

A：不可以。同一商品仅能支持一个"7天无理由"规则，抖店后台按类目配置 N 选 1（N=1 或 2 或 3……），不可同时多选。

*依据：RULE-001 抖音电商"7天无理由退货"规则（四、常见问题）*

**Q3：新旧"7天无理由"售后政策切换期间的订单按哪个政策算？**

A：按照用户下单时商品详情页展示的"7天无理由"规则为准，可参考交易快照（用户可享受的售后政策以用户下单时刻为准）。

*依据：RULE-001 抖音电商"7天无理由退货"规则（四、常见问题）*

## 价格保护（价保）

**Q4：京东价格保护（价保）周期如何计算？**

A：分两类——① 自营订单（不含厂商配送）：商品签收前或签收后 7/15/30/90/180/365 天（从签收第二天 00:00:00 起算）；② 第三方商家/厂商配送订单：下单后 7/15/30/90/180/365 天内（从提交订单时间起算 168/360/720/2160/4320/8760 小时内）。具体周期见商品页面价保服务标识。

*依据：HELP-001 京东价格保护服务FAQ（二）*

**Q5：换货订单的价格保护时效怎么算？**

A：换货订单的价格保护时效以原订单为准，不因换货重新计算。

*依据：HELP-001 京东价格保护服务FAQ（四）*
