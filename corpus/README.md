## 3. 抓取与清洗步骤

1. **采集**：法规用 `fetch` 官方页面全文；平台规则优先取官方公开页（淘江湖/京东帮助/拼多多帮助），官方页 JS 渲染或反爬时改用公开转载全文（晓多/电商派/卖家网/女装促销汇/v兔/找评网等），并在 frontmatter 记录 `source`（实际抓取 URL）与 `original_source`（原始出处）。
2. **清洗**：剔除转载页的营销推广尾部段落（在 frontmatter `note` 标注）；法规全文保留条文结构；`食品安全法` 仅保留与电商/网络食品直接相关条款，标注「节选」；部分平台规则为要点整理，frontmatter 标注。
3. **格式**：每篇 md 带 frontmatter：`doc_id / title / source / source_title / original_source? / collected_at / type / category / tags / license / note?`。
4. **去重**：以「同一规则主题 + 同一平台」去重（如「商家违规行为管理总则」晓多 blog/4133 与 ecommerce/5910 重复，只收一篇）；跨平台同名规则（如各平台「七天无理由退货」）视为不同文档，保留。

### 去重结果

- 抖音「商家违规行为管理总则」：3 个转载源去重后收 1 篇；
- 「淘宝七天无理由退货规范」变更公示与正文合并收 1 篇（正文含特殊完好标准）；
- 京东「价格保护」：商家规则（RULE-020）与消费者 FAQ（HELP-001）角度不同，分别保留；
- 最终 **54 篇**，无重复 doc_id，无重复主题+平台组合。

## 4. 合规说明（红线）

- **只收公开可浏览页面**：不绕过任何访问控制、不登录、不碰商业数据库、不写爬虫硬啃反爬。
- **每篇必有出处 URL**：拿不到可靠出处的宁可不收；官方规则页无法直接抓取时，用公开转载全文并双重标注出处。
- **法规以政府公开版本为准**：来源均为 gov.cn / samr.gov.cn / cac.gov.cn / npc.gov.cn 官方发布文本。
- **license**：① 法律法规文本属于政府公开信息，可自由复制传播；② 平台规则文本用于本项目（个人开源、非商业）的评测语料，标注来源与原始出处，属于合理使用的资料汇编用途；③ 若对外分发，建议以「原始链接 + 引用」方式呈现，不打包售卖规则原文。
- **禁止编造**：所有条文/数字均来自上述来源原文，未做任何虚构。

## 5. 禁限售词表 `compliance/words.json`

- 结构：`_comment` 记来源；`severity_levels` 定义三档（severe=法律法规明令禁止/违法信息；high=广告法禁止的绝对化/权威/医疗/迷信用语；medium=易误导夸大表述）；`words` 按类别组织，每词含 `severity`。
- 来源：广告法第九条、抖音广告禁用词细则（RULE-014）、网络信息内容生态治理规定第六/七条、淘宝违禁信息规则（RULE-021，含涉军违禁）、化妆品条例第三十七条、食品安全法第七十一/七十三条、公开「2025 新广告法违禁词汇总」（腾讯新闻，来源中国品牌与防伪/FDA食安云）。
- **当前 348 词**（severe 119 / high 220 / medium 9，8 个分组）；已达标 ≥300。注意：诱导消费与限定时间类为场景化敏感词，子串命中不代表必然违规（compliance 引擎按子串匹配，存在少量误报，属词表设计已知取舍，见 apps/api/src/skills/executors/builtin/compliance.ts 注释）。

## 6. golden 测试集 v1

### 6.1 题型分布（100 题）

| 题型 | 数量 | 说明 |
|---|---|---|
| 单跳事实 single_hop | 40 | 单篇文档可直接找到答案 |
| 多跳综合 multi_hop | 30 | 需跨 2+ 篇对照（含跨平台、法律↔平台） |
| 数值规则 numeric | 20 | 带数字的规则（7天/168小时/退一赔十/违约金等） |
| 拒答陷阱 refusal_trap | 10 | 语料无答案，正确行为=拒答 |

### 6.2 标注口径

- 每题含 `goldChunk`（`{docId, docName, chunkId, page}`）：`chunkId = {docId}:{章节/条文}`；多跳题另含 `goldChunk2`；拒答题 `goldChunk=null` 且 `refuse=true` + `reason`。
- 同时保留 `goldKeywords`（2-4 个特征词组）——供 30-评测方案「关键词命中近似 Recall」的评测入口使用（chunk 级 gold 过重，关键词命中是个人项目量级的诚实近似）。
- `page` 字段：md 语料无物理页码，以「条文号/章节名」近似（如「第二十五条」「3.1.1」），法规 PDF 若有页码可在入库时回填。
- 出题方式：LLM 从语料反向生成草题 + 人工过滤（本批 100 题由 LLM 预标注，gold 均核验指向真实存在的 docId+条文）。
